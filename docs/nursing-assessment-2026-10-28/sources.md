# Sources used for the Nursing assessment (2026-10-28): access, reuse and what was collected

Only bibliographic **facts** were collected (title, ISSN/eISSN, publisher, country, homepage, subject labels, indexing status, counts of works by year). No descriptions,
abstracts, cover images or other prose were copied. Every candidate row in `eligible-candidates.csv` carries the source URL it came from and the verification date.

| Source | Used for | Access / reuse conditions found | What we did | Result |
|---|---|---|---|---|
| **EBSCO CINAHL title lists** (`about.ebsco.com/title-lists`: CINAHL Complete coverage + subject lists) | Nursing scope (Nursing discipline), "currently indexed" (no indexing stop date), source type, peer review | The lists are published on EBSCO's public title-list page for download; EBSCO states they show *intended coverage* and are © EBSCO under its Terms of Use. | Downloaded the two public files once (no crawling), kept only the fields above, the raw files are not committed. A CINAHL listing alone is **not** treated as nursing evidence (CINAHL also indexes allied health and general medicine); only the Nursing discipline list counts. | 6,697 CINAHL Complete titles; 328 distinct journals under discipline Nursing |
| **SciELO ArticleMeta API** (`articlemeta.scielo.org`) | Nursing scope (Web of Science area NURSING), status (C = current), homepage, publisher, country | Public API; `www.scielo.org` robots asks for a 10 s crawl delay, the API is used with one request per collection. `search.scielo.org` is behind a bot challenge and was **not** touched. | One request per collection (20 collections, 2,182 journals), filtered to Nursing | 44 nursing candidates, 35 already held, 9 not held (1 eligible) |
| **NLM Catalog** (E-utilities) | Nursing scope (NLM subject "Nursing"), currently-indexed flag, country | Public E-utilities, polite use | Subject queries as in the NLM import; no endorsement or MEDLINE claim is made anywhere | 1,295 Nursing-subject serials the planner had found new |
| **OpenAlex** (local copy of the OA and non-OA journal sources, plus `sources/issn:` for year-wise counts) | Topic-based nursing scope, works per year, homepage, DOAJ flag | Public API with the project's key (not printed or stored) | Nursing topic share only counts core nursing subfields (Nutrition and Dietetics is excluded) | 450 nursing-topic journals, 172 net-new |
| **Crossref REST API** | Works per year (DOIs), publisher, title check | Public API, polite pool | `journals/{issn}` | used for all evidence |
| **PubMed E-utilities** | Articles 2024–2026 by ISSN | Public | only when neither Crossref nor OpenAlex showed a recent work | |
| **DOAJ CSV** (`doaj.org/csv`) | Licence declaration for the **Accepted** test; 230 DOAJ journals have a Nursing subject | Published for bulk download | read once | all 230 are already in the catalogue |
| **J-STAGE WebAPI** | Official host platform for Japanese society journals, per ISSN | Terms forbid downloading large amounts of data by mechanical means, so the title list is **not** scraped; the WebAPI is used one ISSN at a time and only for candidates other sources could not confirm | 12 Japanese candidates queried | none of the 12 is on J-STAGE |
| **INANE Directory of Nursing Journals** (`nursingeditors.com/journals-directory/`) | Would add 275 vetted nursing journals | Page content is CC BY-NC-SA 4.0; the listing is an embedded Airtable view loaded by script, so the page itself contains no entries. Reading Airtable's internal data endpoints would go around the intended interface, so it was **not** done. | Not collected | **Needs a person with access to export it** (names and links only; descriptions must not be copied) |
| **REVENF / BVS Enfermería** | Latin-American nursing journals | `revenf.bvs.br` and `bvsalud.org/enfermeria` answered 403, `enfermeria.bvsalud.org` is unreachable from here | Not collected | Not available programmatically |
| **Elsevier / ScienceDirect, Wolters Kluwer / LWW, Wiley, Taylor & Francis, Sage, Karger, Emerald, MDPI** catalogues | Official publisher nursing lists | Automated requests receive 403 (bot protection) | **Not bypassed** | Not collected; a publisher KBART/title-list file or a manual export is the lawful route |
| **Springer, Thieme** pages | Nursing lists | Springer's nursing page lists no journals (promotional links only); Thieme exposes subjects without a nursing list | Nothing usable | none |
| **Official journal sites** (pilot) | Recent issue evidence | Each host's robots.txt is read first; one request per journal | 40 scope-A candidates probed | 19 disallowed by robots, 16 returned 403/404/400 or errors, 5 reachable (2 showed a 2025+ issue, 1 a 2023–24 issue, 2 nothing recent); **automation is not a reliable route** |

Verification date for everything above: 2026-10-28.
